## Why I Built This Repository

Alongside my Computing degree focused on Networks, Cyber Security and Forensics, I actively build and maintain a personal homelab using technologies such as Proxmox, Docker, MikroTik, Splunk and Pi-hole.

This repository helps document the practical lessons, troubleshooting processes and security concepts I encounter while building projects and completing labs.

The goal is to improve my technical communication skills while creating a professional record of my cybersecurity learning journey.

## Disclaimer

All investigations, labs and testing documented here are performed in legal lab environments, intentionally vulnerable systems or infrastructure I personally own and manage.
